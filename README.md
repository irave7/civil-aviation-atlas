# 民航图鉴

面向 iPhone 和 iPad 的机场、客机和航线图鉴，最低支持 iOS 26 和 iPadOS 26。使用 SwiftUI、MapKit 和 RealityKit。

- 在目录的「外观」中选择跟随系统、浅色「青瓷航空图鉴」或深色「深海飞行仪表」。地图、机场与客机三维、飞行模拟采用独立的深色显示区，资料和操控面板适配两套外观。
- 标准构建从地球进入。默认显示民航运输机场，可独立开启直升机场和其他机场，点选后进入三维场景。
- 标准构建的机场页包含三维场区、实景、平面图及航线资料。双指可旋转平面图。中国大陆默认使用 Apple 地图在当地提供的影像，美国本土、日本、法国、西班牙、荷兰及瑞士机场可使用当地公开正射影像。场区建模精度取决于各机场的公开资料。
- 三维视图用双指缩放镜头，三指张开拆分、捏合并拢部件。拆分进度悬浮在画布上。支持内部结构的模型可单指双击切换透视，双指双击切换剖视。「触控教程」可从目录和三维模型工具栏打开。
- 航线和航班详情在应用内展示，实时情况以受支持的官方来源为限。距离为大圆距离，置顶最远航线以收录范围为限。航线探索支持国内与全球航程、客机外部三维、互动操纵、观测风速、预设气流、三套离线普通话预制配音、可选系统朗读与本机自定义涂装。关联实景与公开航班观测随构建和资料覆盖提供。
- 大陆审查配置提供离线机场目录、航线探索和客机三维查看。正式发布的备案、地图及数据授权事项见[中国大陆 App Store 发布手册](docs/mainland-release.md)。
- 独立的「航线模拟」可在地球航图、驾驶舱和机外之间切换。驾驶舱展示按机型配置的仪表和交互，航前准备、滑出、起飞、巡航、着陆及滑入配有离线中文提示和音效。地面轨迹按公开资料使用跑道和连通的滑行道，资料不足时标注参考路径。采用时间压缩和通用客机响应模型。阶段检查及复盘流程参考 [FlightGear 检查单](https://wiki.flightgear.org/Checklists) 和 [X-Plane 手册](https://www.x-plane.com/manuals/desktop/)。
- 自由航线的出发机场和模拟机型选择器优先显示可用收藏。「航线关卡」包含 10 条中国大陆航线、12 条全球航线和 12 座代表机场，按收录的班表、历史航班和经核实的不经停记录编排。通关进度在本机保存。
- 航前和抵达可播报 19 座机场的名称，并提供分地区的备选台词。模拟选项可切换 8 家航司的普通话或英语原创广播，并可试听。航司配音、机场导览和关卡介绍随包离线播放。
- 标准构建的驾驶舱前视与机外视角跟随同一条航迹，使用 Apple 地图的实景地形作为背景。载入影像期间展示模拟前视或机外场景。

## 构建与校验

在 Xcode 中打开 `AirportAtlas.xcodeproj`，选择 `AirportAtlas` 或 `AirportAtlasMainlandReview` scheme，以及 iPhone 或 iPad 模拟器。

```sh
./Build/build.sh simulator
python3 Build/check-data.py
python3 Build/prepare-mainland-catalog.py --check
swiftc -D CHECK_TOUCH_MOVEMENT App/FlightSimulation.swift App/ModelTouchMovement.swift Build/Checks/FlightSimulationChecks.swift -o /tmp/atlas-flight-checks
/tmp/atlas-flight-checks
```

用 `xcrun simctl list devices available` 查询模拟器 UUID，再运行 `./Build/build.sh test SIMULATOR_UUID`。设备打包使用归档命令，发布由拥有相应团队权限的账号完成。
