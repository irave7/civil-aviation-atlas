# 民航图鉴

面向 iPad 的机场、客机和航线图鉴。使用 SwiftUI、MapKit 和 RealityKit，最低支持 iPadOS 26。

- 地球入口支持旋转、缩放及点选机场，点选后直接进入三维模型。
- 机场页提供三维场区、实景、平面图及航线资料。场区建模程度取决于各机场已有的公开数据。
- 客机可以选择内部结构、透视、剖视、拆分、客舱布局和参考涂装。
- 航线同时展示有来源的历史实飞记录、航司公布的班表样本及可用的实时看板。距离为大圆距离，置顶最远航线以收录范围为限。

## 构建与校验

在 Xcode 中打开 `AirportAtlas.xcodeproj`，选择 `AirportAtlas` Scheme 和 iPad 模拟器。命令行使用已安装的 iPadOS SDK。

```sh
./Build/build.sh simulator
python3 Build/check-data.py
```

用 `xcrun simctl list devices available` 查询模拟器 UUID，再运行 `./Build/build.sh test SIMULATOR_UUID`。设备打包使用归档命令，发布由拥有相应团队权限的账号完成。
